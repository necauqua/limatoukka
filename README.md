## limatoukka

This is the source code of my Twitch bot, that initially was behind Twitch Plays
Noita, but then evolved into a more general-purpose bot I use for my Twitch
channel.

It is not prepared to be easily used, so if you want to run it yourself, you'll
have to figure out/set up/disable certain things.

I am putting it out in public just for people to see the code (and as a tertiary
backup or whatever).
